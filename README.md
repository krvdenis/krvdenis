### 🚀 Мои ключевые проекты (Портфолио)

*   **[ExploreWithMe](https://github.com/krvdenis/java-explore-with-me)** — Микросервисная распределенная платформа организации событий на стеке Spring Boot, PostgreSQL и Docker. Реализовал Stateless REST API с JWT-безопасностью (JJWT 0.12), многоуровневый доступ к эндпоинтам и динамическую фильтрацию через Querydsl.
*   **[ShareIt](https://github.com/krvdenis/java-shareit)** — P2P-платформа для шеринга вещей (двухуровневая архитектура Gateway + Server). Настроил жесткую валидацию временных интервалов, пагинацию списков и написал развитую тестовую модель, покрыв бизнес-логику тестами на 90% (Mockito, WebMvcTest).
*   **[Filmorate](https://github.com/krvdenis/java-filmorate)** — Бэкенд-сервис для оценки фильмов. Успешно провел архитектурный рефакторинг слоя данных, переведя приложение со структур In-Memory на встроенную реляционную БД H2 с помощью Spring JDBC с сохранением 100% обратной совместимости API.
